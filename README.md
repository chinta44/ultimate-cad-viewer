# Ultimate CAD Viewer

## 概要
このリポジトリは「Ultimate CAD Viewer」の静的ウェブアプリ（ブラウザで動作するCADビューワー）を収めています。
リポジトリには index.html と関連する画像アセットが含まれており、追加のビルドは不要でローカルや静的ホスティング上で動作します。

## 主な内容
- index.html: アプリ本体（ブラウザで開いて動作を確認できます）
- 各種ファビコン・ロゴ画像

> 注意: 本リポジトリ内の実際の機能・対応フォーマットはソースコード（index.html 等）を参照してください。

## インストール / 起動方法
このプロジェクトは静的ファイルで構成されているため、基本的にはブラウザで index.html を直接開くだけで動作します。以下は推奨の確認方法です。

- 直接開く（簡易確認）
  1. リポジトリをローカルにクローンします。
     git clone https://github.com/chinta44/ultimate-cad-viewer.git
  2. クローンしたディレクトリを開き、index.html をブラウザで開きます。

- ローカルHTTPサーバーで動かす（ブラウザのセキュリティ制約や外部リソース読み込みの確認に便利）
  - Python 3 がある場合:
    cd ultimate-cad-viewer
    python -m http.server 8000
    ブラウザで http://localhost:8000 を開く
  - Node.js の簡易サーバー (serve を使う場合):
    npm install -g serve
    serve -s .

- GitHub Pages に公開する
  1. GitHub リポジトリの Settings → Pages で公開ブランチを選択（通常は main）
  2. ルートに index.html があれば自動的に公開されます

## 使い方
1. ブラウザで index.html を開くとアプリが起動します。
2. UI 上の操作方法（ファイルの読み込み、カメラ操作、表示切替など）はアプリ内のコントロールに従ってください。

※ 具体的な操作や対応フォーマットは index.html のスクリプト部分をご確認ください。
